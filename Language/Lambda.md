### 람다식
> 람다식은 익명 함수(Anonymous Function)의 한 종류로서, 코드를 간단하게 표현하기 위해 사용한다.

### 구현
```
(parameters) => expression
```
> 여기서 'parameters'는 입력 매개변수를, 'expresstion'은 실행할 코드 블록을 나타낸다.
> 일반적으로 람다식은 짧고 간단한 함수들을 표현하기 위해 사용된다.

### 특징
1. 익명성
    > 별도의 메서드를 정의하지 않고도 함수를 사용 할 수 있다.
1. 간결성
    > 간단한 로직을 표현할 때, 전통적인 메서드 정의보다 더 짧고 읽기 쉽게 표현이 가능하다.
    >> 기본적인 메서드 정의 : 
    ```
    public int Square(int x)
    {
        return x * x;
    }
    ```
    >> 람다식 정의 : 
    ```
    Func<int, int> square = x => x * x;
    ```
1. 함수형 프로그래밍
    > 람다식은 C#에서 함수형 프로그래밍의 일부 개념을 구현 할 수 있고,
    함수 자체를 변수에 할당하거나 다른 함수에 전달 할 수 있다.
1. 표현식과 문
